# Mi CV React

CV personal responsive desarrollado con React y Vite.

## Requisitos

- Node.js 18 o superior
- npm

## Ejecutar el proyecto

npm install
npm run dev

Abre la URL que muestra Vite en el navegador.


La aplicación incluye navegación interna, modo claro/oscuro, secciones renderizadas desde arrays y descarga del CV mediante la opción de impresión del navegador.
